# 🧮 Operadores Aritméticos en Java

Este repositorio contiene la evidencia de aprendizaje sobre el uso de variables y operadores aritméticos en Java, desarrollada como parte de la materia de Computación en Java.

## 📝 Descripción del Proyecto
El programa define variables de tipo flotante y realiza cuatro operaciones matemáticas combinadas (sumas, restas, multiplicaciones y divisiones), imprimiendo los resultados en consola con un formato estructurado.
